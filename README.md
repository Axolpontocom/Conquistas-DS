## Sobre o Projeto:

O **Platina Souls** surgiu com o objetivo de aprofundar meus conhecimentos de desenvolvimento web,
juntando uma franquia de jogos no qual eu gosto muito, que é a franquia *Dark souls*. Esse site
nada mais é que um local onde estão listadas todas as conquistas do jogo com checklists para ajudar
players interessados em alcançar o 100% do jogo á se organizarem.

## Funcionalidades
- [x] Navegação fluida entre os jogos da franquia (Dark Souls 1, 2 e 3) ![Status do Projeto](https://img.shields.io/badge/em%20desenvolvimento-yellow?style=flat)
- [x] Sistema de checklist interativo para acompanhamento de conquistas.
- [x] Salvamento automático do progresso do usuário via *LocalStorage*.
