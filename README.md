# Conquistas Dark Souls

Site simples para listar informações e conquistas relacionadas à série Dark Souls.

## Como abrir
- Abra o arquivo [index.html](index.html) no seu navegador (duplo clique ou via `File → Open`).

## Estrutura do projeto
- `index.html` — página principal do site
- `style.css` — estilos do site
- `img/` — imagens usadas no site
- `jogos/DS2.html` — página específica do jogo Dark Souls 2
- `LICENSE` — licença do projeto

## Contribuindo
